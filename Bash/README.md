----------------------------------------------
Failed Login Analyzer
----------------------------------------------
A Bash script that analyzes any failed login attempts from "/var/log/auth.log". This project helped refine Bash fundamentals while building a security-focused tool for monitoring unauthorized access attempts on Linux systems.

----------------------------------------------
Features
----------------------------------------------
* Reads failed login attempts from auth.log
* Displays raw failed login entries
* Extracts and counts attacker IP addresses
* Identifies usernames targeted during failed logins

----------------------------------------------
How to Run
----------------------------------------------
* Open a Linux terminal
* Navigate to the script location 
* Run "sudo ./failed-login-analyzer.sh"
