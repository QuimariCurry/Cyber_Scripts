----------------------------------------------
Python File Scanner
----------------------------------------------
A simple Python script using Spyder 3.13 that scans a folder, lists all files, displays their sizes, and generated SHA256 hashes. This project helped me practice my Python fundamentals while building a small automation tool.

----------------------------------------------
Features
----------------------------------------------
* Scans any folder on your system
* Shows full file path
* Displays file sizes in bytes
* Generates SHA256 hashes
* Beginner-friendly script

----------------------------------------------
How to Run
----------------------------------------------
* Open Spyder and run "file_scanner.py"
* Enter the folder path when prompted
