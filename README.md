# Cyber_Scripts
A collection of beginner-friendly Python and Bash scripts created to practice automation, system analysis, and foundational scripting skills.
## Purpose
This repo showcases practical workflows, file analysis, and cross platform fundamentals that are relevant to SOC< DFIR, and cybersecurity practice.
## How to Use
* Navigate into any project folder to view its README and run the associated script
* Python scripts can be run in Spyder or any Python IDE
* Bash scripts can be run on any Linux terminal like Kali or Ubuntu
